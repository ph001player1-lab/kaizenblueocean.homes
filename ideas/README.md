# Реестр идей

Здесь лежат идеи, которые люди прислали через раздел сайта «Идеи», вместе с оценкой по
шкале «насилие — любовь». Правила оценки — в [`docs/ideas-rubric.md`](../docs/ideas-rubric.md).

- `ГГГГ-ММ-ДД-slug.md` — одна идея: поля оценки сверху, ниже разбор и текст автора.
- `calibration/` — исторические случаи с известным исходом. Это отметки на шкале, а не идеи
  для рейтинга.

Сборка (`tools/build_site.py`) делает из этих файлов рейтинг на странице `/ideas/` и кладёт
каждый файл на сайт для скачивания: `/ideas/files/<id>.md`.

Идеи публикуются под лицензией CC BY 4.0: их можно читать, скачивать и передавать дальше
со ссылкой на автора.
