# kaizenblueocean.homes

Сайт проекта Kaizen Blue Ocean. «Мир начинается дома».
Автор — Николай Владимирович Буленков. Сайт: https://kaizenblueocean.homes

- [`docs/concept.md`](docs/concept.md) — концепция сайта и все решения по нему.
- [`src/`](src/README.md) — исходник сайта: главная, «Деньги», «Любовь», «Время» на двух языках.
- `tools/` — сборка сайта (`build_site.py`), данные карты мира (`build_map_data.py`), текстуры планеты, превью ссылок.
- `materials/` — исходные материалы автора: книга «Поток любви. Инструкция по эксплуатации» (PDF, DOCX), обложки и фото автора.

Каждый пуш в основную ветку собирает сайт и публикует его на GitHub Pages.
