# Голоса за Утопию: Google Таблица + Telegram

Сайт статический, поэтому голоса принимает маленький скрипт внутри Google Таблицы автора.
Как только человек отправляет форму на странице «Утопия», скрипт:

1. проверяет голос (имя, контакт, два согласия, защита от ботов);
2. записывает строку в лист «Голоса»;
3. сразу пишет автору в Telegram: имя, страна, контакт и ссылка на строку.

Счётчик и список «Кто уже хочет» сайт берёт у того же скрипта. Контакты наружу не отдаются.
Имя показывается на сайте, только если человек это разрешил. Снять имя с сайта — убрать
галочку «На сайте» в таблице.

## Установка (один раз, минут 10)

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → придумайте имя, например
   «Утопия · голоса». BotFather пришлёт токен — длинную строку с двоеточием. Никому её не
   пересылайте. Откройте своего бота и нажмите «Старт».
2. **Скрипт.** Откройте таблицу → «Расширения» → «Apps Script». Удалите всё в файле `Код.gs`
   и вставьте содержимое `Code.gs` из этой папки. Сохраните.
3. **Токен.** Слева «Настройки проекта» (шестерёнка) → «Свойства скрипта» → «Добавить
   свойство»: название `TELEGRAM_TOKEN`, значение — токен от BotFather. Сохраните.
4. **Проверка.** Вернитесь в редактор, вверху выберите функцию `setup` → «Выполнить».
   Google попросит доступ к таблице и к внешним запросам — разрешите. Бот пришлёт
   «Готово». В таблице появится лист «Голоса».
5. **Публикация.** «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение»:
   - «Выполнять как» — «Я»;
   - «У кого есть доступ» — «Все».

   Нажмите «Начать развёртывание» и скопируйте адрес веб-приложения
   (`https://script.google.com/macros/s/…/exec`).
6. **Сайт.** Адрес вписывается в `ENDPOINT` в `src/utopia.js`. После этого форма начинает
   принимать голоса, а на странице появляются счётчик и список.

Если потом поменяете код скрипта, сделайте «Управление развёртываниями» → карандаш →
«Новая версия»: тогда адрес останется прежним.

## Лист «Голоса»

| Колонка | Что в ней |
|---|---|
| Время | когда пришёл голос |
| Имя | как человек просил показать |
| Контакт | Telegram, WhatsApp или почта — только для автора |
| Страна | код страны (RUS, THA…) или пусто |
| Разрешил показать | галочка самого человека |
| На сайте | галочка автора: снимите, чтобы скрыть имя |
| Детей | сколько детей хотят вместе с ним |
| Язык | на каком языке голосовал |
| Ключ | скрытая колонка: контакт без пробелов и знаков, чтобы один человек не голосовал дважды |

Удалить голос по просьбе человека — удалить его строку.
