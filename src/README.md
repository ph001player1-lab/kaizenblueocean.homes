# Сайт kaizenblueocean.homes — исходник

Здесь всё, из чего собирается сайт: главная и три страницы — «Деньги»,
«Любовь» и «Время» — на английском (по умолчанию) и русском.

`index.html` — один файл на все страницы и оба языка: тексты стоят рядом
(`data-l="en"` и `data-l="ru"`), страницы переключаются якорями `#money`,
`#love` и `#time`. Так текст удобно править, а файл можно открыть как прототип.

## Как устроен сайт

`tools/build_site.py` делает из исходника отдельные страницы, у каждой свой адрес:

```
/            /money/            /love/            /time/
/ru/         /ru/money/         /ru/love/         /ru/time/
```

Плюс книги в `/files/`, страница 404, `sitemap.xml`, `robots.txt`, `llms.txt`
и `CNAME`. У каждой страницы свои заголовок, описание и картинка для превью
ссылок. Шрифты, Three.js и данные карты лежат на самом сайте: внешних запросов нет.

Каждый пуш в основную ветку запускает `.github/workflows/pages.yml`: он
собирает сайт и публикует его на GitHub Pages.

## Как посмотреть у себя

```
python3 tools/build_site.py
cd _site && python3 -m http.server 8000
```

и открыть http://localhost:8000. Прототип целиком — `cd src && python3 -m http.server 8000`.
Нужен браузер с WebGL 2; без него страница показывает текст и переключатели,
но без планеты.

## Что внутри

| Файл | Что делает |
|---|---|
| `index.html` | разметка всех страниц на двух языках |
| `styles.css` | вёрстка, светлая тема |
| `app.js` | кнопки, подсказка «Нажмите», шкала здоровья, объяснения; в прототипе — ещё страницы и язык |
| `planet.js` | Земля на Three.js: поверхность, огни, очаги, облака, атмосфера |
| `atlas.js` | карта мира с вкладками «Любовь», «Деньги», «Время» и маленькая карта эпох на главной |
| `assets/map/world.json` | данные карты — собирает `tools/build_map_data.py` |
| `vendor/` | Three.js r170 (MIT) |
| `assets/fonts/` | Unbounded, Onest, JetBrains Mono (SIL Open Font License 1.1) |
| `assets/planet/` | текстуры и данные планеты — собирает `tools/build_planet_assets.py` |
| `assets/img/` | обложки книги (русская и английская) и фото автора |
| `assets/mg/` | картинки Market Game с marketgame.club |
| `assets/og/`, `assets/icons/` | превью ссылок и иконки — рисует `tools/make_og.cjs` (только одну страницу: `node tools/make_og.cjs time`) |

Книги лежат в `materials/`: `potok-lyubvi.pdf` и `the-flow-of-love.pdf`.
Английскую обложку делает `tools/make_en_cover.py` из фотографии русской.

Всё состояние планеты — два числа от 0 до 1: `kaizen` и `blueOcean`.
Шейдеры читают их напрямую, переходы идут 4,5 секунды.

| | «Деньги» выкл. | «Деньги» вкл. |
|---|---|---|
| **«Любовь» выкл.** | смог, мутная вода, выжженная земля, красные очаги | вода чистая и синяя, огни холодные, земля сухая |
| **«Любовь» вкл.** | зелень, тёплые огни, вода ещё мутная, очаги тлеют | воздух и вода чистые, земля зелёная; последние очаги медленно гаснут, но не до нуля |

Под планетой — шкала «Здоровье планеты»: любовь закрывает одну половину,
деньги — другую. После каждого нажатия появляется объяснение: что изменилось
и что это значит.

## Карта мира

Одна и та же карта стоит на страницах «Деньги», «Любовь» и «Время»; на каждой
сразу открыта своя вкладка. Блок в разметке — `<section class="atlas"
data-atlas="money">`: заголовок и короткий текст для тех, у кого не работает
JavaScript, остальное рисует `atlas.js`. Маленькая карта эпох на главной —
`[data-atlas-mini]`, мировые числа в тексте — `[data-world="no_el|cook_fire|ai"]`.

- **Любовь** — индекс гражданских свобод V-Dem, 0–100.
- **Деньги** — сколько в день у нижних 10% (Всемирный банк, PIP).
- **Время** — эпоха: та, что была до первого изобретения, которого у человека
  нет. Ступени: электричество → чистая плита → интернет → 5G → ИИ; дальше —
  6G, AGI, роботы и базовый доход, там пока никого.

Обновить данные:

```
rm -rf .cache/map-raw && python3 tools/build_map_data.py
```

Числа на странице «Время» и в блоке на главной `atlas.js` берёт из данных; в
разметке — запасной текст. После обновления данных поправьте и его, и цифры в
описаниях страницы «Время» в `tools/build_site.py`.

## Данные и лицензии

- Дневная поверхность — NASA Blue Marble Next Generation, июль 2004.
- Ночные огни — NASA Black Marble 2016.
- Облака — NASA Blue Marble.
- Суша, озёра и города — Natural Earth.

Всё это общественное достояние. Пересобрать текстуры:

```
python3 tools/build_planet_assets.py
```

Скрипт сам скачает исходники в `.cache/planet-raw/`.

Данные карты (`assets/map/world.json`):

- границы — Natural Earth 1:110m, общественное достояние;
- свобода — V-Dem через Our World in Data;
- доходы — Всемирный банк, Poverty and Inequality Platform; подушка — Global Findex; электричество, плита, интернет, население — Всемирный банк (CC BY 4.0);
- 5G — МСЭ через базу целей устойчивого развития ООН;
- ИИ — Microsoft AI Diffusion Report через Our World in Data;
- роботы — IFR, World Robotics 2025 (цифры из пресс-релиза, вписаны в скрипт);
- метки: изолированные народы — Survival International, амиши — Young Center, базовый доход — власти Аляски и Макао, GiveDirectly, Kela.

Источники перечислены и под самой картой.
