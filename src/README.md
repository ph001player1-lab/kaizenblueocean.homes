# Сайт kaizenblueocean.homes — исходник

Здесь всё, из чего собирается сайт: главная и две страницы, «Деньги» и
«Любовь», на английском (по умолчанию) и русском.

`index.html` — один файл на все страницы и оба языка: тексты стоят рядом
(`data-l="en"` и `data-l="ru"`), страницы переключаются якорями `#money` и
`#love`. Так текст удобно править, а файл можно открыть как прототип.

## Как устроен сайт

`tools/build_site.py` делает из исходника отдельные страницы, у каждой свой адрес:

```
/            /money/            /love/
/ru/         /ru/money/         /ru/love/
```

Плюс книги в `/files/`, страница 404, `sitemap.xml`, `robots.txt`, `llms.txt`
и `CNAME`. У каждой страницы свои заголовок, описание и картинка для превью
ссылок. Шрифты и Three.js лежат на самом сайте: внешних запросов нет.

Каждый пуш в основную ветку запускает `.github/workflows/pages.yml`: он
собирает сайт и публикует его на GitHub Pages.

## Как посмотреть у себя

```
python3 tools/build_site.py
cd _site && python3 -m http.server 8000
```

и открыть http://localhost:8000. Прототип целиком — `cd src && python3 -m http.server 8000`.
Нужен браузер с WebGL 2; без него страница показывает текст и переключатели,
но без планеты.

## Что внутри

| Файл | Что делает |
|---|---|
| `index.html` | разметка всех страниц на двух языках |
| `styles.css` | вёрстка, светлая тема |
| `app.js` | переключатели, подписи состояний; в прототипе — ещё страницы и язык |
| `planet.js` | Земля на Three.js: поверхность, огни, очаги, облака, атмосфера, кольцо |
| `vendor/` | Three.js r170 (MIT) |
| `assets/fonts/` | Unbounded, Onest, JetBrains Mono (SIL Open Font License 1.1) |
| `assets/planet/` | текстуры и данные планеты — собирает `tools/build_planet_assets.py` |
| `assets/img/` | обложки книги (русская и английская) и фото автора |
| `assets/mg/` | картинки Market Game с marketgame.club |
| `assets/og/`, `assets/icons/` | превью ссылок и иконки — рисует `tools/make_og.cjs` |

Книги лежат в `materials/`: `potok-lyubvi.pdf` и `the-flow-of-love.pdf`.
Английскую обложку делает `tools/make_en_cover.py` из фотографии русской.

Всё состояние планеты — два числа от 0 до 1: `kaizen` и `blueOcean`.
Шейдеры читают их напрямую, переходы идут 4,5 секунды.

| | Blue Ocean выкл. | Blue Ocean вкл. |
|---|---|---|
| **Kaizen выкл.** | смог, мутная вода, выжженная земля, красные очаги; кольца нет — только пунктир | вода чистая и синяя, огни холодные; построена синяя половина кольца |
| **Kaizen вкл.** | зелень, тёплые огни, очаги ещё тлеют; построена золотая половина кольца | воздух чистый, кольцо сомкнулось; последние очаги медленно гаснут, но не до нуля |

## Данные и лицензии

- Дневная поверхность — NASA Blue Marble Next Generation, июль 2004.
- Ночные огни — NASA Black Marble 2016.
- Облака — NASA Blue Marble.
- Суша, озёра и города — Natural Earth.

Всё это общественное достояние. Пересобрать текстуры:

```
python3 tools/build_planet_assets.py
```

Скрипт сам скачает исходники в `.cache/planet-raw/`.
