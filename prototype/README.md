# Прототип главного экрана

Этап 1 из концепции (`docs/concept.md`, раздел 17): планета в четырёх состояниях,
переключатели Kaizen и Blue Ocean, подписи, русский и английский.
Цель — проверить, считывается ли метафора, до того как строить остальной сайт.

## Как посмотреть

```
cd prototype
python3 -m http.server 8000
```

и открыть http://localhost:8000. Нужен браузер с WebGL 2; без него страница
показывает текст и переключатели, но без планеты.

## Что внутри

| Файл | Что делает |
|---|---|
| `index.html` | разметка: главный экран, «Где пути сходятся», подвал |
| `styles.css` | вёрстка; один тёмный визуальный мир — космос |
| `app.js` | переключатели, подписи состояний, язык, запоминание в браузере |
| `planet.js` | Земля на Three.js: поверхность, огни, очаги, облака, атмосфера, дуги и нити |
| `assets/planet/` | текстуры и данные, собранные `tools/build_planet_assets.py` |

Всё состояние планеты — два числа от 0 до 1: `kaizen` и `blueOcean`.
Шейдеры читают их напрямую, переходы идут 4,5 секунды.

| | Blue Ocean выкл. | Blue Ocean вкл. |
|---|---|---|
| **Kaizen выкл.** | очаги износа, смог, красные мерцающие огни | океаны светятся, дуги обмена, но огни холодные |
| **Kaizen вкл.** | огни теплеют, золотые нити, зелень | всё вместе; последние очаги медленно гаснут, но не до нуля |

Three.js загружается с jsDelivr (версия 0.170.0) — для прототипа. На сайте
библиотеку положим рядом с кодом.

## Данные и лицензии

- Дневная поверхность — NASA Blue Marble Next Generation, июль 2004.
- Ночные огни — NASA Black Marble 2016.
- Облака — NASA Blue Marble.
- Суша, озёра и города — Natural Earth.

Всё это общественное достояние. Пересобрать текстуры:

```
python3 tools/build_planet_assets.py
```

Скрипт сам скачает исходники в `.cache/planet-raw/`.
