# Прототип сайта

Главная и две страницы, «Деньги» и «Любовь», на русском и английском.
Сделано по концепции (`docs/concept.md`, версия 1.4): светлая тема, планета
с кольцом, после первого экрана — два блока, а из них — страницы, которые
ведут к одному действию: записаться на Market Game или скачать книгу.

## Как посмотреть

```
cd prototype
python3 -m http.server 8000
```

и открыть http://localhost:8000. Нужен браузер с WebGL 2; без него страница
показывает текст и переключатели, но без планеты.

Страницы переключаются якорями: `#money` — «Деньги», `#love` — «Любовь»,
любой другой якорь — главная. Так прототип работает и как обычный сайт,
и внутри артефакта. На настоящем сайте это будут отдельные адреса
`/money/` и `/love/`.

## Что внутри

| Файл | Что делает |
|---|---|
| `index.html` | разметка всех трёх страниц; тексты на двух языках (`data-l="ru"` и `data-l="en"`) |
| `styles.css` | вёрстка, светлая тема |
| `app.js` | страницы, переключатели, подписи состояний, язык, запоминание в браузере |
| `planet.js` | Земля на Three.js: поверхность, огни, очаги, облака, атмосфера, кольцо |
| `assets/planet/` | текстуры и данные, собранные `tools/build_planet_assets.py` |
| `assets/img/` | книга и фото автора |
| `assets/mg/` | картинки Market Game с marketgame.club |

Всё состояние планеты — два числа от 0 до 1: `kaizen` и `blueOcean`.
Шейдеры читают их напрямую, переходы идут 4,5 секунды.

| | Blue Ocean выкл. | Blue Ocean вкл. |
|---|---|---|
| **Kaizen выкл.** | смог, мутная вода, выжженная земля, красные очаги; кольца нет — только пунктир | вода чистая и синяя, огни холодные; построена синяя половина кольца |
| **Kaizen вкл.** | зелень, тёплые огни, очаги ещё тлеют; построена золотая половина кольца | воздух чистый, кольцо сомкнулось; последние очаги медленно гаснут, но не до нуля |

Three.js загружается с jsDelivr (версия 0.170.0) — для прототипа. На сайте
библиотеку положим рядом с кодом. Кнопка «Скачать книгу» пока ведёт на PDF
в репозитории на GitHub; на сайте файл будет лежать рядом со страницами.

## Данные и лицензии

- Дневная поверхность — NASA Blue Marble Next Generation, июль 2004.
- Ночные огни — NASA Black Marble 2016.
- Облака — NASA Blue Marble.
- Суша, озёра и города — Natural Earth.

Всё это общественное достояние. Пересобрать текстуры:

```
python3 tools/build_planet_assets.py
```

Скрипт сам скачает исходники в `.cache/planet-raw/`.
