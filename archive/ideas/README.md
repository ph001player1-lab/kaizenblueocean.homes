# Архив: раздел «Идеи»

Раздел «Идеи» (реестр идей со шкалой «насилие — любовь») был на сайте с 7 по 24 ноября 2026
года. Автор снял его: сейчас он неактуален. Вместо него на сайте страница «Утопия».

Здесь сохранено то, что может пригодиться, если раздел вернётся:

- `rubric.md` — правила оценки идей, версия 0.2: пять флагов (Перенос, Откат, Выход, Мост,
  Опекун) и уровень от −3 до +3;
- `calibration/` — пять исторических случаев с известным исходом: сухой закон в США,
  Португалия 2001, Орегон 2021, кибуцы, обязательная школа;
- `prompt-ru.md`, `prompt-en.md` — промпт для интервью с ИИ посетителя (формат `KBO-IDEA v1`);
- `registry-README.md` — описание реестра идей.

Код страницы (разметка, `ideas.js`, стили, сборка рейтинга в `tools/build_site.py`) — в истории
git: коммит `6036e37`. Подробные прогоны пяти случаев — в документе
«Коэффициент 111 — рубрика оценки идей v0.1» (Claude Doc автора).
